#  201 Mercadinho

Um sistema de **mercadinho desenvolvido em C** como projeto escolar, simulando uma pequena loja de doces com estoque, carrinho de compras, caixa eletrônico e conversor de moedas.

##  Sobre o projeto

O **201 Mercadinho** foi desenvolvido para praticar conceitos fundamentais da linguagem C, utilizando funções, estruturas (`struct`), vetores, variáveis, condicionais, estruturas de repetição e operações matemáticas.

O programa possui uma interface executada diretamente no terminal, com menus interativos e diferentes funcionalidades.

##  Funcionalidades

*  **Loja de doces**

  * Visualização dos produtos disponíveis
  * Preços por unidade
  * Controle de estoque
  * Compra de produtos
  * Adição de produtos ao carrinho

*  **Carrinho de compras**

  * Cálculo automático do valor total
  * Verificação do saldo disponível
  * Pagamento do carrinho

*  **Caixa eletrônico**

  * Consulta e alteração do saldo
  * Simulação de operações bancárias

*  **Conversor de moedas**

  * Real → Dólar
  * Real → Euro
  * Real → Libra
  * Real → Iene
  * Real → Bitcoin
  * Dólar → Real
  * Euro → Real
  * Libra → Real

*  **Controle de estoque**

  * Quantidade disponível de cada produto
  * Atualização do estoque após as compras
  * Aviso quando um produto está sem estoque

##  Conceitos de C utilizados

Durante o desenvolvimento foram utilizados:

* `struct`
* Vetores
* Funções
* Parâmetros de funções
* Variáveis globais
* `if` / `else`
* `switch`
* `while`
* `for`
* `scanf`
* `printf`
* Operações matemáticas
* Manipulação de dados em estruturas

##  Produtos

O sistema possui um catálogo inicial de doces, como:

* Brigadeiro tradicional
* Pipoca de sal
* Pipoca de chocolate
* Pipoca de ninho
* Brownie

##  Tecnologias

* **Linguagem:** C
* **Execução:** Terminal/Console

##  Objetivo

Este projeto foi desenvolvido como atividade escolar com o objetivo de colocar em prática os conhecimentos aprendidos em programação e desenvolver um sistema interativo utilizando a linguagem C.
